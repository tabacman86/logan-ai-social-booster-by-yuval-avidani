# Social Media Auto Engager

תוסף דפדפן חכם שמבצע לייקים ותגובות אוטומטיות ב-LinkedIn ו-Facebook באמצעות בינה מלאכותית של Cohere.

## תכונות

- 🤖 תגובות אוטומטיות מבוססות AI באמצעות Cohere
- ❤️ לייקים אוטומטיים לפוסטים
- 🎯 תמיכה ב-LinkedIn ו-Facebook
- 🎨 מגוון סגנונות תגובות (מקצועי, ידידותי, מעודד, מחשיב)
- ⚙️ הגדרות גמישות עבור כל פלטפורמה
- 🔒 אחסון מאובטח של מפתח API

## התקנה

### שלב 1: בנייה
```bash
npm install
npm run build
```

### שלב 2: התקנה בדפדפן
1. פתח את Chrome
2. עבור ל-`chrome://extensions/`
3. הפעל "Developer mode" בפינה הימנית העליונה
4. לחץ על "Load unpacked" ובחר את תיקיית `dist`

### שלב 3: הגדרה
1. לחץ על אייקון התוסף בסרגל הכלים
2. הזן את מפתח ה-API של Cohere (ראה למטה איך להשיג)
3. בחר את ההגדרות הרצויות
4. שמור הגדרות

## קבלת מפתח API של Cohere

1. עבור לאתר [Cohere](https://cohere.ai/)
2. הירשם לחשבון חינמי
3. עבור לדשבורד
4. צור מפתח API חדש
5. העתק והדבק אותו בתוסף

## שימוש

### הפעלה
1. עבור ל-LinkedIn או Facebook
2. הפעל את התוסף דרך הפופאפ
3. התוסף יזהה פוסטים חדשים ויגיב אליהם אוטומטית

### הגדרות זמינות
- **לייק אוטומטי**: מבצע לייק אוטומטי לפוסטים
- **תגובות אוטומטיות**: כותב תגובות מבוססות AI
- **סגנון תגובות**: 
  - מקצועי - תגובות עסקיות ומקצועיות
  - ידידותי - תגובות חמות ונעימות
  - מעודד - תגובות תומכות ומעודדות
  - מחשיב - תגובות מעמיקות ומחשיבות

## אזהרות חשובות

⚠️ **השתמש באחריות**: התוסף מבצע פעולות אוטומטיות ברשתות החברתיות. וודא שההתנהגות עומדת בכללי הקהילה של הפלטפורמות.

⚠️ **מגבלות קצב**: התוסף מבצע השהיות אקראיות כדי להיראות טבעי יותר, אך עדיין כדאי לפקח על הפעילות.

⚠️ **פרטיות**: מפתח ה-API נשמר מקומית בדפדפן ואינו נשלח לשום מקום מלבד Cohere.

## פתרון בעיות

### התוסף לא מזהה פוסטים
- רענן את הדף
- וודא שההגדרות מופעלות
- בדוק את Console (F12) לשגיאות

### תגובות לא נוצרות
- וודא שמפתח ה-API של Cohere תקין
- בדוק את Console לשגיאות
- וודא שיש לך זיכויים ב-Cohere

### התוסף לא מופיע
- וודא שבניית הפרויקט הושלמה בהצלחה
- נסה לרענן את דף ההרחבות
- בדוק שהתיקייה הנכונה נטענה

## פיתוח

### מבנה הפרויקט
```
├── src/
│   ├── background.js      # Service Worker
│   ├── popup.js          # לוגיקת הפופאפ
│   ├── popup.html        # ממשק הפופאפ
│   ├── popup.css         # עיצוב הפופאפ
│   ├── linkedin-content.js  # תסריט עבור LinkedIn
│   └── facebook-content.js  # תסריט עבור Facebook
├── icons/                # אייקונים
├── manifest.json        # הגדרות התוסף
└── webpack.config.js    # הגדרות Webpack
```

### פקודות פיתוח
```bash
npm run dev      # בנייה במצב פיתוח עם watch
npm run build    # בנייה לפרודקשן
```
